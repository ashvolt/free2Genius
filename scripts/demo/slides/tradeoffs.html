What this does not do

Stated limits

Latency: 80s local
Too slow for a live surface. Honest fit is batch drafting with human review — recorded as unmet in spec 005.
Synthetic data
Validates the pipeline, not the business case. Real uplift numbers would move.
No grammar off-process
In-process llama.cpp constrains output with GBNF — malformed tool calls impossible. The server backend relies on validation plus a bounded repair loop. Measured per backend, not assumed.
Guardrails check grounding, not reasoning
Every figure can trace to a tool call while the sentence built from them draws the wrong conclusion. Observed on camera with a 7B model. No automated check in this system catches it — a human reviewer does.
Fairness is a monitor
It reports the policy-induced gap. It does not optimise it away.
No authentication
Demonstration service. Must not be exposed publicly.
